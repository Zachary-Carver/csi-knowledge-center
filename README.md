# CSI Knowledge Center

A machine-readable educational authority hub for CSI: Clean Scene Investigators. The commercial service website remains https://www.cleansceneinvestigators.com.

## Publishing

This static site deploys through the included GitHub Pages workflow on every push to `main`. Its custom domain is `answers.cleansceneinvestigators.com`.

## Scope

Crime scene, trauma and biohazard, unattended death and decomposition, hoarding, odor-source, vehicle biohazard, and extreme-mess cleanup in DFW, Denton County, and North Texas. No street address is published.
